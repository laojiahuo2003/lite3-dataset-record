# 具身巡检数据集采集方案

## 1. 建地图（只需一次）

```bash
cd ~/robot-deep_robotics-lite3
# manifest 里 map_mode 改成 mapping
./start.sh
# 遥控慢速走一圈，浏览器 8091 点 Save
./stop.sh
# map_mode 改回 localization
```

## 2. 巡检采集

```bash
# 启动定位
cd ~/robot-deep_robotics-lite3
./start.sh

# 另开终端，录制
cd ~/code/lite3-dataset-record
./bin/record_session.sh                    # 自动编号 001, 002, ...
./bin/record_session.sh 003 "夜间巡检"     # 指定编号 + 备注

# 遥控走完路线 → Ctrl-C 停止（自动抓 GT 快照）
./stop.sh
```

录制话题：RGB 图像、深度图、LiDAR 点云、里程计、TF、IMU。

## 3. 提取处理

```bash
# 一键全量提取
python3 scripts/assemble_dataset.py -s 001

# 增量模式（跳过已完成步骤）
python3 scripts/assemble_dataset.py -s 001 --skip-existing

# 只提取部分模块
python3 scripts/assemble_dataset.py -s 001 --only images,odom

# 指定场景目录（默认 scenes1）
python3 scripts/assemble_dataset.py -s 001 --scene scenes2
```

内部自动跑 10 个 Phase：里程计 → TF轨迹 → 图像 → 深度图 → 点云 → 模板拷贝 → 数据增强 → 视频编码 → 记忆节点 → 清单生成。输出到 `datasets/<scene>/session_XXX/`。

## 4. 视频编码

```bash
# 从已提取的图像帧生成视频流（assemble_dataset 内部自动调用）
python3 scripts/build_videos.py datasets/scenes1/session_001

# 只生成 RGB 视频
python3 scripts/build_videos.py datasets/scenes1/session_001 --no-depth --no-preview

# 只生成深度热力图预览（不给领导看就跳过）
python3 scripts/build_videos.py datasets/scenes1/session_001 --no-rgb --no-depth

# 跳过预览视频（节省时间）
python3 scripts/build_videos.py datasets/scenes1/session_001 --no-preview
```

输出三种视频（videos/ 下）：

| 文件 | 编码 | 大小参考 | 说明 |
|------|------|---------|------|
| rgb_main.mp4 | H.264 | ~4 MB | RGB 视频流，训练/播放 |
| depth_aligned.mkv | FFV1 无损 | ~40 MB | 深度原始值打包 (B=低8位, G=高8位) |
| depth_preview.mp4 | H.264 Turbo | ~7 MB | 深度热力图预览，给人看的 |

深度视频说明：
- `depth_aligned.mkv` 是训练用的无损格式，uint16 深度值分拆到 B/G 双通道，用 `unpack_depth_bgr_to_u16()` 还原
- `depth_preview.mp4` 是给人看的热力图（Turbo 色板），普通播放器直接播放，**数据已失真，不能用于训练**

## 5. 可视化

```bash
python3 scripts/visualize_dataset.py
```

## 6. 清理（重新来过）

```bash
# 一键清空 raw/ 和 datasets/ 下所有数据
./bin/clean.sh
```

## 7. 手动补抓 GT 快照

录制时已自动抓取。若失败，在 `./stop.sh` 之前手动补跑：

```bash
python3 scripts/snapshot_ground_truth.py 003
python3 scripts/snapshot_ground_truth.py 003 --min-conf 0.3
```

## 目录结构

```
raw/session_XXX/              # 原始 rosbag2（不动）
datasets/<scene>/             # 最终数据集
├── session_XXX/
│   ├── images/ depth/ lidar/           # 传感器帧
│   ├── images_index.csv depth_index.csv
│   ├── odometry.csv base_link_pose.csv
│   ├── memory_nodes.json
│   ├── objects.yaml camera_calib.yaml
│   ├── meta.yaml dataset_manifest.yaml
│   └── videos/                          # 视频流
│       ├── rgb_main.mp4                  #   RGB H.264
│       ├── depth_aligned.mkv             #   深度 FFV1 无损
│       └── depth_preview.mp4             #   深度 Turbo 热力图预览
└── scenes/<map_id>/                     # 场景定义（多 session 共享）
    ├── scene.yaml
    └── layout.png
```
