# 数据上传与归档（Hugging Face）

采集完的数据（`datasets/` 提取结果，可选 `raw/` 原始 bag）归档到 Hugging Face，
方便团队共享、异地备份、后期发布成公开 benchmark。

## 1. 仓库信息

| 项 | 值 |
|----|----|
| 账号 | `laojiahuo` |
| 数据集仓库 | `laojiahuo/scribemem-bench`（**私有**，发布前可改公开） |
| 网页地址 | https://huggingface.co/datasets/laojiahuo/scribemem-bench |
| 同步脚本 | `scripts/hf_sync.py`（Python API，不依赖 git/git-lfs，断点续传、增量跳过） |

## 2. 首次配置（只需一次）

```bash
# 1) 创建 token（需 Read+Write 权限），浏览器打开：
#    https://huggingface.co/settings/tokens
#    注意：登录用直连 huggingface.co，不要走镜像（镜像 auth 校验是坏的）

# 2) 登录，token 会存入 ~/.cache/huggingface/token
hf auth login
# 粘贴 token

# 3) 创建数据集仓库（私有），脚本首次运行时已自动创建过
hf repo create scribemem-bench --type=dataset
# 或者用本仓库脚本创建：
#   python3 -c "from huggingface_hub import HfApi; HfApi().create_repo(repo_id='laojiahuo/scribemem-bench', repo_type='dataset', private=True)"
```

> 网络说明：本机直连 `huggingface.co` 稳定可用；`hf-mirror.com` 的
> whoami/auth 校验会误报 "Invalid user token"，**不要**设 `HF_ENDPOINT=https://hf-mirror.com`。
> 若直连偶发变慢/失败，可临时切镜像试下载（镜像 auth 虽坏，但部分下载可能可用）。

## 3. 日常上传

```bash
# 上传提取好的数据集（datasets/scenes1/），增量：只传新增/变化文件
python3 scripts/hf_sync.py upload laojiahuo/scribemem-bench

# 指定场景目录
python3 scripts/hf_sync.py upload laojiahuo/scribemem-bench --scene scenes2

# 连同 raw rosbag 一起传（raw 较大，按需；--sessions 逗号分隔）
python3 scripts/hf_sync.py upload laojiahuo/scribemem-bench --include raw --sessions 002,003
```

远端口录结构与本地一致：

```
scribemem-bench (dataset 仓库)
├── scenes1/session_001/      # 提取好的数据集
├── scenes1/test2/            # 场景定义
└── raw/session_002/          # 原始 rosbag（可选上传）
```

## 4. 下载

```bash
# 任意机器（同样需要先 hf auth login）
python3 scripts/hf_sync.py download laojiahuo/scribemem-bench --local-dir ./hf_data
```

## 5. 存储上限（决定能传多少）

| 限制 | 数值 | 说明 |
|------|------|------|
| 单文件上限 | 50GB | 超过上传失败；本数据集最大文件 ~64MB（depth_aligned.mkv），无忧 |
| 免费私有仓库配额 | ~10GB/仓库 | **主要约束**：单次 session ~600MB → 约 15 次满一个仓库 |
| 免费私有存储总量 | 100GB | 所有私有仓库合计 |
| 公开仓库 | 1TB | 需要扩容可联系 HF |
| 文件数量 | ≤10 万/仓库，≤1 万/文件夹 | 单次 session ~1000 文件，50 次 ~5 万，OK |

应对策略（按推荐排序）：

1. **拆多个私有仓库**（`scribemem-scenes1`、`scribemem-scenes2`…），每个控制在 10GB 内；
2. **仓库设 Public**（1TB 额度）——反正是要发 benchmark 的，发布前不想公开展示就别选；
3. **升级 Pro**（$9/月，每仓库 50GB、私有 1TB+）。

推荐组合：**私有拆仓库先传够用 → 正式发论文时合成一个公开仓库**。

## 6. 常见问题

- **上传失败/中断**：脚本断点续传，重跑同一命令会自动跳过已传文件。
- **"Invalid user token"**：检查是否设了 `HF_ENDPOINT=https://hf-mirror.com`（会误报）；或 token 已失效，重新 `hf auth login`。
- **token 泄露**：token 曾在本机对话中出现过，若机器有其他使用者，去 HF 后台 revoke 并重新建一个再登录。
- **换电脑**：新机器 `hf auth login` 后即可用同一脚本上传/下载，脚本只依赖 `huggingface_hub`。

## 7. 可选：采集完自动上传

把 `hf_sync.py upload` 追加到 `record_session.sh` 末尾即可实现"录完自动归档"，注意上传耗时较长，建议放后台（`nohup … &`）并保留日志。
